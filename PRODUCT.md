# Product: Brian Ooi — Personal Portfolio

## Purpose
A personal portfolio website for Brian Ooi, a Computer Engineering graduate (UTeM, CGPA 3.95) seeking AI engineering and software development roles. The site's job is to make Brian hireable — it must communicate technical credibility, personal character, and creative craft in one scroll.

## Audience
- **Primary**: Technical hiring managers and senior engineers at AI/software companies
- **Secondary**: Recruiters screening for AI/full-stack roles
- **Tertiary**: Peers and the open-source/dev community

## Brand Voice
- Direct and confident, not corporate
- Curious and precise — Brian is an engineer who thinks carefully
- Warm but not casual; professional but not sterile
- Tagline feel: *curious by default. rigorous by habit.*

## Core Sections
1. **Hero** — First impression. Name, role cycler (scramble animation), call to action, photo via PixelTransition hover reveal
2. **About** — Brief personal summary, 4 key facts, animated avatar (EyeTrackingAvatar) with pose cycling + hover lean
3. **Projects** — 2-column card grid showcasing AI/full-stack builds
4. **Skills** — Chip-based skill groups (AI/ML, Backend, Frontend, Tools)
5. **Contact** — Single large email CTA + socials
6. **Footer** — Minimal monospace attribution

## Tech Stack
- React 18 + Vite
- Framer Motion (animations — the primary animation library, use this first)
- GSAP (only for PixelTransition pixel-dissolve effect)
- Lucide React (icons)
- Vanilla CSS with CSS custom properties (no Tailwind)
- No UI component libraries
